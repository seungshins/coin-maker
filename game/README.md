# 귀향의 맹세 v0.2.16

## 진행과 파밍
구역의 희귀 몬스터와 보스를 모두 잡으면 진행합니다. 일반 몬스터는 선택 파밍이며 남겨도 됩니다. 희귀 비율은 일반 생성 몬스터 약 1/7이며 장비/젬 보상이 보장됩니다.
엔드게임 T1~5: 3구역, 진 보스 1. T6~11: 5구역, 중간 보스1 + 진 보스1. T12~16: 7구역, 중간 보스3 + 진 보스1.
마지막 필드의 목표를 처치하면 보라색 포탈이 열립니다. 포탈 가까이에서 클릭하거나 상호작용 키(F 기본)를 누르면 별도 진 보스 투기장으로 갑니다. 진 보스 처치 후 다음 티어가 열립니다. 투기장 안에서도 저장·재개됩니다.
엔드게임은 화산 나선 / S자 계곡 / C자 해안 / 십자 신전 / 트로이 성곽 / 선박 연결 전장을 순환합니다. 해상 전장은 고정된 선박과 연결 다리이며 조종하는 해전은 아닙니다. 액트는 기존 동선을 유지하며 전투 공간과 밀도를 확대했습니다.
프로테우스의 사슬은 희귀·보스의 속성만 12초 탈취합니다. 일반 몬스터는 제외됩니다.

## 100레벨 성장
액트별 첫 진행 경험치 목표는 5 / 9 / 13 / 17 / 21 / 25 / 30레벨입니다. 일반 몬스터를 더 잡으면 다소 높아질 수 있습니다. 구역 목표 경험치는 중복 지급되지 않습니다.
30레벨 이후 T1~16에서 100레벨까지 성장합니다. 60레벨 이후 필요 경험치가 추가 증가합니다.
주스킬 기본 성장: 레벨당 +2%, 100레벨에서 2.98배. 힘은 근접, 민첩은 활·투척, 지능은 마법 피해를 배분 1당 +1% 올립니다. 체력·마나 등도 100레벨에 맞춰 조정했습니다.
새 장비 기본값은 레벨 절반을 반영하며, 등급 배율은 일반/마법/희귀/영웅/전설/신화 1/1.15/1.4/1.8/2.5/3.3입니다. 기존 장비와 보유 젬은 삭제하지 않습니다.
주스킬·보조 젬 착용 레벨은 등급순 1/8/20/40/65/85입니다. 낮은 등급도 유지하고 높은 희귀도부터 정렬합니다. 레벨 미달 카드는 붉은 장착 불가 배너와 필요 레벨을 표시합니다.
고유 효과와 모든 젬은 아테나의 전당 권능 도감에서 확인합니다.

## 경제와 획득 필터
가차 골드 비용 = 50 + 8×(레벨−1) + 35×티어. 조각 비용 = 5 + floor((레벨−1)/15). 두 결제 방식은 종류별 보장 횟수를 공유합니다.
예: Lv1 50골드, Lv30 T1 317골드, Lv100 T16 1402골드.
희귀 드롭은 Lv15, 영웅은 Lv30, 전설은 Lv55, 신화는 Lv75부터 가능합니다. Lv1 가차는 일반90%/마법10%이며 희귀 이상은 나오지 않습니다.
가차는 필드보다 고등급 가중치가 낮습니다. 50회 보장은 Lv1~19 마법 이상, Lv20~39 희귀 이상, Lv40+ 영웅 이상입니다. 현재 확률은 상점에서 표시합니다.
장비 획득 필터는 설정에서 변경합니다. 자동 기본값은 액트 전체 / 엔드게임 희귀 이상입니다. 제외된 장비는 표시·자동 줍기·구역 정리 시 수거에서 제외되며, 필터를 바꾸면 다시 주울 수 있습니다. 젬은 제외하지 않습니다.
자동 줍기 반경은160(기존50)입니다. 장비에 이름·등급·바닥 고리, 영웅 이상에 빛 기둥을 표시합니다.
장비 판매는 희귀도별 일괄/개별 판매를 지원합니다. 일반~영웅 즉시, 전설/신화 확인 팝업. 장착품은 제외합니다. 판매가12+등급×8골드.

## 조작과 화면
기본 WASD 이동 / 좌·우 클릭과 Q E R T 스킬 / Space 회피 / 1·2 포션 / I 가방 / K 스킬 / F 상호작용 / Esc 취소·일시정지.
설정 또는 마을 오른쪽 메뉴에서 조작 안내·키 변경·기본값 복원을 지원합니다. 키는 저장되고 중복 배정을 막습니다. 마우스 좌·우와 Esc는 고정입니다.
720p~QHD, 창/작업 표시줄을 남기는 테두리 없는 전체 창/전체 화면을 지원합니다. 해상도에 따른 자동 메뉴 배율과 전장 배율을 적용하되 체력·마나·경험치는 화면 가장자리에 유지합니다.
유지 버프와 일시 버프/탈취 권능은 좌상단 아이콘과 남은 시간으로 표시합니다. 마을 안내는 오른쪽 반투명 메뉴입니다.
출항 시 포션2회분, 체력40%/마나50%를4초간 회복. 일반/희귀/보스 처치로 .08/.2/.5회분 충전합니다. 중간 저장은 잔량과 회복 상태를 보존합니다.

## 저장 및 검증
기존 캐릭터와 장비를 유지합니다. 지형 리비전 변경 시 보상과 완료 구역을 유지하면서 미완료 배치를 재구성합니다. 고등급 젬의 새 착용 레벨은 기존 보유분에도 적용됩니다.
20개 검사: 전투·저장·가차·진행·포탈·키 변경·100레벨·획득 필터. 액트30 도달과 초반 가차5000회 시뮬레이션, UI 렌더링을 확인했습니다.
장시간 실제 파밍 밸런스는 플레이 피드백으로 추가 조정이 필요합니다. 모델링은 절차적 스타일이며 macOS/Linux 실제 기기 실행은 미검증입니다.

## v0.2.13 성장·무기·전투

버프 효과는 Lv1 기본값50%에서 Lv100 125%까지 성장합니다. 점멸140→330, 도약126→297 거리로 성장합니다. 귀환 투사체는 적을 맞힌 즉시 돌아오지 않고 남은 비행 시간(최소0.55초)만큼 더 진행합니다.
검·창·마법봉·활 장비와 든 모델, 스킬 장착/사용 조건을 연결했습니다. 옛 무기는 검으로 호환합니다. 상점 확정 구매에서 기본 무기60골드. 창 스킬은 창, 활 스킬은 활, 주문은 마법봉, 기타 근접은 검이 필요합니다. v0.2.14부터 네 무기를 동시에 장착할 수 있습니다.

장비창 캐릭터 옆 스탯 +1/+5/+10, 부족하면 남은 만큼 배분. 초기화50+레벨×2골드, 배분 포인트 전부 반환. 배분하지 않은 경우 비용을 내지 않습니다.
보조 젬 적용 불가는 붉은 경고 띠와 테두리로 표시하고 레벨 부족도 함께 표시합니다. 캐릭터 장식과 몬스터 근육/갑옷, 보스 어깨 실루엣 및 해안 바위층을 보강했습니다. 기존 절차적 모델의 개선이며 외부 고해상도 모델 교체는 아닙니다.

## v0.2.14 장비·버프·화면
설정은 캐릭터와 별도로 저장하며 다음 실행의 UI 구성 후 해상도와 창/테두리 없는 창/전체 화면을 복원합니다.
장비는 검·창·마법봉·활 4칸과 흉갑·유물·투구·장갑·신발·반지2개·목걸이로 총12칸. 기존3칸/9칸 저장은 빈 슬롯을 추가해 호환합니다. 네 무기를 동시에 장착하고 스킬별 무기 피해를 사용하며 손의 모델도 전환합니다. 네 장착 무기는 모두 판매에서 보호됩니다. 반지는 비어 있는 첫 반지 슬롯에 자동 장착하며, 두 번째 반지를 교체하려면 해당 슬롯을 먼저 해제하세요.
흉갑 체력, 투구/장갑 방어도, 신발 이동속도(최대30%), 반지/목걸이 공격·시전 속도. 방어도 감소율은 방어도/(방어도+100+레벨×12), 상한35%. 신규 고유: 투구 지면 주문 반경+10%/마나재생, 장갑 밀치기+12/주스킬피해+8%. 개별 옵션은 툴팁, 전체 효과는 장비 아래, 스탯은 별도 우측 카드입니다.
화염·냉기·번개 유지 버프는 각각 명중 피해의5~12.5%를 추가하며 서로 합연산. 기존과 동일하게 최대2개만 활성화. 명중 원소 이펙트 표시. 레벨 기본 피해 성장1.8%, 집중 보조 배율1.15/1.21/1.30/1.40/1.52/1.65로 조정했습니다.
주스킬/보조젬 연결 불가 경고 띠, 장비 검·창·마법봉·활 아이콘 구분. 지정 무기 가차는 일반 장비 가차와 비용·희귀도 확률·보장 횟수 공유. 스킬 쿨타임은 시계형 남은 비율과 올림한 초 숫자로 표시합니다.
최신 실행 파일은 GitHub Releases에서 운영체제별로 내려받습니다. Windows ZIP을 풀고 exe 실행, Linux는 실행 권한 부여 후 실행. macOS 빌드는 서명·공증되지 않았으며 macOS/Linux 실기기 동작은 미검증입니다.

## v0.2.15 스킬과 소환
삼신의 분광창: 창 찌르기70% 피해 뒤 전방3방향 화염/냉기/번개 줄기를 각각45% 피해로 방출. 같은 시전의 줄기는 동일 적에 중복 명중하지 않습니다.
망령 전사: 2기, 부채꼴 영혼 베기. 세이렌: 1기, 냉기 음파와30% 감속. 히드라: 1기, 최대3대상 독 타격과 짧은 독 지대. 소환수 전체 상한4기, 기본15초, 마법봉 사용.
소환 전용 보조4종: 불멸의 계약(체력+30~130%, 피해 감소8~22%), 영혼의 박동(공격/시전 속도+10~50%), 종말의 서약(8초 체력 소모, 사망/만료 시 공격 피해1.2~2.5배 폭발), 공명의 합창(반경45~105 범위 공격, 피해25% 감소). 상한 때문에 교체되는 소환수는 폭발하지 않습니다. 소환수 상태는 저장됩니다.
보조 슬롯은 Lv1/5/15/30/60/85에 하나씩, 최대6개입니다.
새 고유 효과: 명중12% 저주(2초 재사용), 명중10% 충격파(1.5초 재사용, 명중 피해35%), 명중8% 무작위3초 버프(8초 재사용), 배분한 힘/지능1당 피해0.15%(각 최대30%). 고유 발동 피해로 다시 발동하지 않으며 소환수 공격도 발동 제외입니다. 고유 효과 도감에서 확인할 수 있습니다.
중복 주스킬/보조 젬의 조각 보상은 가차만 지급합니다. 필드와 상자에서 이미 보유한 동일 등급 젬은 조각 없이 소멸합니다. 기존 조각은 유지합니다.
20개 자동 검사와 화면 렌더 검수를 통과했습니다. 장시간 실전 파밍 밸런스는 추가 피드백으로 조정합니다.

## v0.2.16 유도 보조
아르테미스의 인도: 화살과 투사체 주스킬 전용. 전방 주변450거리 안의 적을 추적하며 속도는 유지합니다. 회전 속도는 등급별 초당69/89/109/132/158/183도, 피해15% 감소. 이미 관통한 적과 죽은 적은 제외합니다. 귀환 구간에서는 유도하지 않으며 기존 지형 충돌/사거리 제한은 유지합니다. 확정 구매·가차·필드 전리품·도감에 연결됩니다.

### 다크 모델과 보스 전투
캐릭터 전용 보조 조명과 재질 대비, 짙은 피부/갑옷/망토 색상으로 배경과 구분했습니다. 새 외부 고해상도 모델 교체가 아니라 기존 입체 모델 개선입니다.
근접 보스는 1.15초 내려찍기/1.3초 전방140도 휘두르기를 번갈아 사용합니다. 준비 시점의 목표를 고정하며 공격 후0.75초 빈틈이 있습니다. 빨간 원 밖 또는 부채꼴 뒤로 피하세요.
기존 고르곤 보스는 메두사로 표시하며 뱀 하체와 지팡이를 사용합니다. 1.5초 예고 후 독침5발 또는 전방120도 석화 시선을 사용합니다. 시선에 맞으면2.5초 이동속도45% 감소하며 측면 이동/회피로 피할 수 있습니다. 패턴과 예고 상태는 저장됩니다.

소환수는 열린 구역에 남은 적을 계속 공격하며 독립적인 공격 동작과 끼임 복귀를 지원합니다.
