# 개발 환경과 첫 구현

## 기술 결정

2026-09-10 공식 Godot GitHub latest 릴리스 API에서 4.7.2-stable을 확인하고 일반 Windows x64 배포본을 다운로드했다. 프로젝트는 이 버전으로 고정한다. typed GDScript를 사용하고 외부 언어 런타임 없이 Godot 기본 편집기로 개발한다.

공식 출처: https://github.com/godotengine/godot/releases/tag/4.7.2-stable

- Godot 4.7.2 일반판: 필수. 이번 작업 환경의 work/tools/godot에 배치했다.
- .NET SDK, Unity, Node 기반 게임 빌드, 서버/DB: 현재 게임 실행에 필요하지 않다.
- Windows export templates: 배포용 exe 제작 시 엔진과 같은 4.7.2 버전이 필요하다. 아직 설치하지 않았다.
- Git: 버전 관리에 필요. 현재 환경의 Git HTTPS helper 문제로 원격 동기화가 미완료다. 로컬 코드는 보존되어 있다.
- 외부 그림 편집기와 음원 도구: 실제 에셋 제작 시 선택한다. 현재 도형은 코드로 그리며 별도 구매 에셋이 없다.

Godot 공식 시스템 요구사항은 [공식 문서](https://docs.godotengine.org/en/stable/about/system_requirements.html)를 참고한다. 실제 게임 최소사양은 부하 측정 후 결정한다.

## 구현 범위

쿼터뷰 마름모 바닥, 발밑 정렬된 임시 캐릭터, WASD 이동, 조준 투사체, 회피, 추격하는 적 12마리, 피격 flash/소멸 효과, 처치 골드, 일시정지와 재시작을 넣었다. 충돌 계산은 선분 기반으로 빠른 투사체 누락을 검사한다.

아레나 스크립트는 P1 테스트용이다. 실제 장비/스킬 데이터와 저장을 연결할 때 Actor/SkillRunner 등의 계획된 컴포넌트로 분리한다. 현재 도형 걷기/소멸은 최종 스프라이트 모션이 아니다. 전투 자원과 회피 타이밍도 최종 규칙 적용 전이다.

## 검증과 제한

피해 계산 189 예제, 저항 상한, 고속 투사체 선분 적중/빗나감, 아이소 좌표 왕복 자동 검증을 통과했다. headless 장면 실행에서 스크립트 파싱/실행 오류는 없었다. 현재 환경에서 기본 AppData 쓰기와 시스템 인증서 접근 관련 엔진 오류가 보고되었다. 게임 저장은 미구현이며 이 상태로 저장 검증이 끝났다고 간주하지 않는다.

그래픽 렌더링의 실제 조작 검수와 Windows export는 아직 수행하지 않았다. 저장·드롭·가차·도박·성장·캠페인은 기획 상태다.

## 기획에서 다음에 구체화할 것

첫 아레나가 동작하므로 추가 대형 시스템 없이 적 패턴/공격 가독성/실제 조작부터 검증한다. 그 다음 스킬 ID별 데이터와 첫 스테이지 보상표를 작성한다. 전체 캠페인 대사와 모든 신화 장비를 미리 확정할 필요는 없다.
