# 레벨·능력치와 추가 규칙

2026-09-10 설계 초안. 숫자는 데이터로 조정할 시작값이며 실제 밸런스 검증 결과가 아니다. 장비와 젬 조합이 성장의 중심이고 레벨·능력치는 이를 보완한다.

## 통화와 성장 축

- 통화: 골드. 상점 구매, 가차, 장비 판매에 사용한다.
- 캐릭터 레벨: 경험치로 상승, 기본 체력·배분 포인트·보조 슬롯 개방.
- 장비 아이템 레벨: 옵션 수치 범위. 캐릭터 레벨과 다른 값이며 지역 진행도로 결정.
- 젬 희귀도: 보조 효과의 성능/변형. 캐릭터 레벨이 올라도 젬 희귀도가 자동 상승하지 않는다.
- 젬 자체 경험치와 젬 레벨은 초기 제외한다. 성장 축을 동시에 늘리지 않는다.

## 레벨과 보조 슬롯

| 캐릭터 레벨 | 사용할 수 있는 보조 슬롯 |
|---|---:|
| 1~4 | 1 |
| 5~14 | 2 |
| 15~29 | 3 |
| 30 이상 | 4 |

첫 데모 상한 Lv.10, 전체 게임 목표 상한 Lv.50. 캠페인 완료 목표 Lv.30~35, 이후 엔드게임에서 Lv.50까지 성장한다. 액트 입장은 스토리 진행도로, 보조 슬롯은 레벨만으로 개방한다. 레벨이 오르면 슬롯을 사용할 수 있는 것이며 젬을 무작위로 지급하지 않는다. 첫 기본 보조는 튜토리얼 확정 보상으로 준다.

첫 15분 내 Lv.5에 도달해 두 보조의 조합을 경험하는 것이 속도 목표다. 전체 캠페인 시간은 액트 1 실측 후 결정한다.

초기 다음 레벨 필요 경험치: `xp_to_next(L) = 100 + 40 × (L-1) + 10 × (L-1)^2`. 정수로 저장하고 실제 요구량은 레벨 테이블로 관리한다. 여러 레벨을 한 번에 올리는 초과 경험치도 처리한다. 상한에서는 경험치 바가 MAX로 표시되며 추가 포인트를 주지 않는다.

적 경험치는 EnemyDefinition의 base_xp, 지역 배율, 적/플레이어 레벨 차이 배율로 계산한다. 초기에는 낮은 지역 반복 방지용으로 플레이어보다 6레벨 이상 낮은 적 경험치를 25%로 제한하고 나머지는 100%로 둔다. 보스와 클리어 보너스는 별도 데이터 값이다. 적 레벨은 플레이어 레벨에 자동 동기화하지 않는다.

레벨업은 방 안에서 즉시 적용되지만 체력은 전부 회복하지 않는다. 최대 체력 상승분만 현재 체력에 더한다. 포인트 배분과 재분배는 거점에서만 가능하다. 스탯을 변경해 현재 체력을 반복 회복하는 행동은 막는다.

## 힘·민첩·지능

초기 각각 10, 레벨업마다 자유 배분 포인트 2. 초기 직업별 차이는 없다. 무료 전체 재분배를 거점에서 제공한다. 스탯 요구치로 젬/장비 착용을 제한하지 않는다.

효과는 시작값 10을 초과한 유효 능력치만 계산한다: `B = max(0, effective_attribute - 10)`. 장비와 버프의 능력치도 합산한다.

| 능력치 | 포인트당 효과 | 보완 역할 |
|---|---|---|
| 힘 | 최대 체력 +2, 근접 태그 피해 increased +0.2% | 근접 생존과 피해 |
| 민첩 | 모든 주스킬 행동 속도 increased +0.1%, 이동 속도 increased +0.05% | 공격 템포와 이동 |
| 지능 | 비근접 주스킬 피해 increased +0.2% | 투사체/원거리 피해 |

근접 주스킬에는 힘의 피해 보너스만, 나머지에는 지능의 피해 보너스만 적용한다. 속성과 공격 방식은 별개이므로 번개 근접 공격도 근접으로 분류한다. 민첩의 행동 속도는 공격/시전 선딜·후딜에 동일하게 적용하되 회피 쿨다운·고유 발동 쿨다운·상태효과 틱에는 적용하지 않는다.

능력치 출처 보너스의 초기 상한: 힘 체력 +300, 힘/지능 피해 각각 +30%, 민첩 행동 속도 +15%, 이동 속도 +7.5%. 장비의 다른 직접 옵션까지 이 상한에 포함하지 않는다. 모든 출처를 합친 행동 속도 배율은 별도 2.0 상한을 둔다. 최종 스킬 발동 간격은 최소 0.1초로 제한한다.

Lv.1 기본 체력 100, 레벨당 기본 체력 +10. 예를 들어 Lv.10에서 포인트 18개를 모두 힘에 배분하면 장비가 없을 때 최대 체력 226, 근접 피해 increased +3.6%다. 능력치가 대형 보조 효과보다 작게 기여하도록 시작한다.

상한·포인트 수·레벨별 기본 체력·각 계수는 AttributeRules 데이터에서 변경한다. 초반/캠페인 종료/최대 레벨에서 힘 몰입·민첩 몰입·지능 몰입·균등 배분의 피해와 생존을 비교한다. 최적 배분이 하나로 고정되면 계수를 먼저 조정하며 패시브 트리를 추가해 해결하지 않는다.

## 전투 자원·회복·실패

- 초기 마나/스태미나 없음. 주스킬은 발동 간격으로 제한한다. 민첩은 일반 주스킬의 동작 시간을 줄이며, 별도 재사용 대기시간이 있는 스킬은 그 제한도 만족해야 한다.
- 회피: 초기 0.25초 이동, 중간 0.15초 무적, 재사용 1.5초. 수치와 구간은 데이터화한다.
- 회복: Q로 최대 체력 40% 회복, 출격당 2회, 사용 간격 10초. 거점 복귀 시 충전. 가차 대상이 아니다.
- 사망: 경험치/레벨/장착 장비 손실 없음. 미정산 골드 50%만 지급하고 클리어 보너스 없음. 소수는 내림.
- 정상 패배 시 획득 경험치와 주운 아이템은 유지하여 별도 정산한다. 비정상 종료는 저장된 방 시작 체크포인트로 되돌아가므로 그 방의 경험치·드롭·체력·레벨 변화도 함께 되돌린다.
- ESC 메뉴, 인벤토리, 창 비활성화 시 전투를 일시정지한다. UI와 저장은 계속 동작한다.

## 인벤토리·드롭의 기본 규칙

골드와 경험치는 적 사망 시 자동 수집한다. 장비는 가까이 가면 획득한다. 초기 장비 보관 용량 100, 젬은 정의 ID별 소유 상태로 관리한다. 장착 변경은 거점에서만 허용한다.

스킬 젬도 적에게서 직접 드롭하며 가까이 가면 획득한다. 드롭 확률과 안전 구간 골드 도박, 저장 경계는 [획득·도박 규칙](08-view-loot-gambling.md)을 따른다.

가차 전에 보관 공간을 검증한다. 전투에서 공간이 부족한 장비는 결과 화면의 미수령 목록에 보관하고 판매/교체 후 처리한다. 미수령 목록이 남으면 다음 출격을 막고, 목록을 저장해 장비를 조용히 버리지 않는다. 잠금·장착 장비는 일괄 판매 제외. 아이템 비교는 피해뿐 아니라 체력·속도·고유 효과도 보여준다.

## 아키텍처 추가

- ExperienceService: 경험치 지급, 복수 레벨업, 잔여 경험치, 레벨 상한 처리. 전투 보상 ID를 재사용해 중복 지급 방지.
- AttributeAllocationService: 미사용 포인트 검증, 거점 배분/초기화, 저장 후 적용. 배분 포인트 합계는 `2×(level-1)`을 넘을 수 없다.
- SlotUnlockResolver: 레벨 → 사용 가능한 슬롯 수를 계산한다. 슬롯 수는 저장하지 않고 규칙에서 파생한다.
- StatsResolver 확장: 레벨 기본값 → 배분/장비 능력치 → 능력치 효과 → 직접 옵션/보조/버프 → 상한 순서. 능력치가 자기 자신을 올리는 순환 효과는 초기 금지한다.
- RunState: 미정산 골드/경험치/아이템, 회복 충전, 방 시작 캐릭터 상태를 보관한다. 방 완료 저장과 패배 정산의 정책을 분리한다.
- PauseController: 전투 시간 정지와 UI 입력을 분리하고 복귀 시 누적된 입력/시간으로 공격이 몰리지 않게 한다.
- Save DTO 추가: level, xp_in_level, allocated_attributes, unclaimed_items, healing_charges. 미사용 포인트와 최종 능력치는 파생한다. 방 체크포인트에도 같은 성장 상태를 포함한다.
- 데이터 추가: progression.json, attribute_rules.json, combat_rules.json. 기존 정의에 enemy_level/base_xp를 추가한다. 전체 상한 변경은 밸런스 버전과 세이브 이전 규칙을 함께 갱신한다.

UI는 레벨·경험치·골드, 남은 배분 포인트, 다음 슬롯 개방 레벨, 능력치 변경 전후를 표시한다. 상태창 표시와 실제 피해 계산은 동일 StatsResolver 결과를 사용한다.

## 앞으로 필요한 기획과 우선순위

| 우선순위 | 남은 명세 | 필요한 시점 |
|---|---|---|
| P0 | 액트 1 방별 적 수·배치·보스 패턴 시간표 | 전투 프로토타입 이후 |
| P0 | 실제 주스킬/보조/장비 ID별 수치 데이터 | 빌드 시스템 구현 전 |
| P0 | 부팅→메뉴→저장 슬롯→거점→전투→결과의 화면 흐름 | 첫 UI 구현 전 |
| P0 | 골드/경험치/드롭의 방별 보상표와 초반 보장 보상 | 경제·성장 통합 전 |
| P1 | 초반 5분 튜토리얼 문구와 안내 종료 조건 | 첫 데모 완성 전 |
| P1 | 저장 슬롯 개수, 수동 백업/내보내기 UI, 입력·접근성 설정 | 배포 테스트 전 |
| P1 | 기준 PC, Windows 배포 패키지, 버전/세이브 호환 정책 | 첫 외부 플레이테스트 전 |
| P2 | 액트별 상세 대사·상위 고유 효과·엔드게임 시련 테이블 | 첫 데모 검증 후 |

큰 시스템의 종류는 충분히 정리되었다. 다음에는 아키텍처를 더 늘리기보다 액트 1의 실제 데이터와 전투 프로토타입으로 수치·조작·제작량을 검증한다.

검증 항목: 경험치 경계/복수 레벨업/상한, 슬롯 Lv.4→5 및 14→15 및 29→30, 포인트 과다 배분 거부, 무료 초기화 반복 시 체력 증가 없음, 저장 복귀 시 레벨과 포인트 일치, 힘/지능 태그 중복 적용 없음, 행동 속도 상한, 사망 정산 중복 없음.
