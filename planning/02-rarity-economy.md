# 희귀도·가차·성장 규칙

이 문서의 확률, 가격, 배율은 초기 실험값이다. 실제 출시 확률로 확정하지 않는다. 현금 결제 없는 획득 골드 기반이다.

일반 구매·가차·판매에 사용하는 통화는 **골드 한 종류**다. 중복 스킬 조각은 해당 스킬 교환에만 쓰는 수집 재료이며 별도 범용 통화로 사용하지 않는다. 스탯 재분배는 초기 무료다.

## 희귀도와 고유 효과

| 등급 | UI 색 | 기본 가차 확률 | 장비 | 스킬 |
|---|---|---:|---|---|
| 일반 | 회색 | 60% | 기본 능력치 | 기본 공격/낮은 보조 수치 |
| 마법 | 파랑 | 27% | 무작위 옵션 1개 | 소폭 강화 |
| 희귀 | 노랑 | 10% | 무작위 옵션 2개 | 유용한 수치와 변형 |
| 영웅 | 보라 | 2.5% | 옵션 3개 또는 영웅 고유 | 강한 보조, 뚜렷한 특화 |
| 전설 | 주황 | 0.45% | 전설 고유 중심 | 큰 배율/다수 투사체 |
| 신화 | 빨강 | 0.05% | 신화 고유 | 최상위 변형/상호작용 |

합계 100%. 색 외에 등급 텍스트와 아이콘으로 구분한다. 장비·스킬 가차는 별도 풀이고 초기에는 같은 등급 확률을 사용한다.

`rarity`와 `unique_effect_id`는 별도 필드다. 고유 효과는 영웅 이상에만 배치한다. 영웅 장비 풀의 고유 비중을 20%, 전설·신화는 100%로 두면 천장 없는 장비 가차의 고유 총확률은 2.5%×20%+0.45%+0.05%=1.0%다. 영웅 풀 안에서 일반 장비 수가 늘어도 20%가 유지되도록 하위 풀을 나눈다. 특정 고유 장비 확률은 해당 하위 풀 내 가중치에 따라 더 낮다.

고유 효과는 낮은 등급에서 무작위 옵션으로 생기지 않는다. 일반 옵션 수치가 좋은 장비도 활용하도록 고유 장비에 모든 최상위 일반 옵션을 함께 주지는 않는다. 희귀도, 아이템 레벨, 옵션 롤을 구분한다. 희귀도는 기능/옵션 구조, 아이템 레벨은 옵션 수치의 상한, 롤은 해당 구간 내 실제 수치다.

## 보조스킬 예시

| 계열 | 일반 | 희귀 | 전설 | 신화 |
|---|---|---|---|---|
| 다중 투사체 | +1발, 피해 ×0.80 | +2발, ×0.85 | +4발, ×0.90 | +6발, ×0.95 |
| 집중 | 피해 ×1.10, 범위 ×0.90 | ×1.25, 범위 ×0.90 | ×1.45, 범위 ×0.90 | ×1.60, 범위 ×0.90 |

같은 계열은 하나만 장착. 이 표는 일부 등급의 예시이고 실제 풀 등록 전에 각 변형을 정의한다. 상위 등급이 성능상 우위가 있는 방향을 수용하되, 투사체 증가는 적 무리 처리에, 집중은 단일 대상에 특화한다.

같은 발사에서 나온 여러 투사체가 한 대상에 동시에 중복 적중하지 않는 것을 기본값으로 한다. 예외 스킬은 별도 적중 상한을 명시한다. 연쇄는 같은 대상을 재방문하지 않는다. 보조가 만든 메아리는 다시 메아리/발동 효과를 발생시키지 않는다. 초기 투사체 수 상한 12, 연쇄 5, 발동 깊이 1을 공통 제한으로 둔다.

## 가차 처리

1. 현재 개방된 풀, 가격, 기본 확률, 천장 상태를 표시한다.
2. 골드·인벤토리 공간·명령 중복 여부를 검증한다.
3. RNG로 등급 → 고유 하위 풀(장비) → 콘텐츠 ID → 옵션 롤을 선택한다.
4. 지불, 결과, 중복 변환, 천장 카운터, RNG 상태를 하나의 저장 트랜잭션으로 확정한다.
5. 저장 성공 후에만 결과 연출을 보여준다. 실패하면 지불과 결과 모두 적용하지 않는다.

풀은 액트/엔드게임 진행도에 따라 개방한다. 가차 장비 레벨은 해금한 최대 진행도에 따라 정하고 현재 장비를 벗었다고 낮아지지 않는다. 유효 후보가 없는 등급/풀은 구매 자체를 막으며 다른 등급으로 조용히 대체하지 않는다.

## 천장과 중복

- 제안: 장비·스킬 각각 50회 이내 영웅 이상 1개 보장. 49회 연속 미획득이면 다음은 영웅 이상을 기존 세 등급의 상대 가중치로 선택한다. 영웅 이상을 얻으면 카운터 초기화.
- 위 표는 천장 적용 전 확률이다. 천장 포함 장기 확률은 시뮬레이션 후 별도 표시한다.
- 신화 0.05%의 천장 없는 기대 횟수는 2,000회이며 획득 보장은 아니다. 캠페인 필수 성능을 신화에 두지 않는다.
- 첫 스킬은 보관, 동일 콘텐츠 ID 중복은 등급별 조각으로 자동 변환한다. 조각으로 개방된 동일 등급 스킬을 확정 교환하는 방향. 비용은 파밍 속도 검증 후 확정.
- 장비는 인스턴스별 보관/판매. 잠금된 장비와 장착 장비는 판매 불가.

## 초기 경제 실험

필드 장비·스킬 젬 드롭 및 골드 도박은 [별도 출처별 테이블](08-view-loot-gambling.md)을 사용한다. 아래 골드 수치는 판매 수입과 도박 순손익까지 포함해 다시 검증한다.

일반 한 판 평균 골드 120, 가차 100, 기본 스킬 확정 구매 200으로 시작한다. 3~5분에 1회 이상 뽑는 흐름을 검증한다. 패배 시 미정산 골드 50%를 정산하고 클리어 보너스는 없다. 판정과 반올림은 서버 없는 단일 도메인 함수에서 한 번만 수행한다. 이미 정산된 보상은 다시 주지 않는다.

스테이지별 골드/분, 가차 횟수/시간, 등급별 획득, 보스 처치 시간, 특정 스킬 미획득 기간을 로컬 테스트 로그로 확인한다. 초기 드롭은 가차 확률을 그대로 복제하지 않고 별도 테이블로 둔다. 보스 대상 파밍 확률은 실제 콘텐츠가 정의될 때 기록한다.
