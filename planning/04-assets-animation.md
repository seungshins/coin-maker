# 에셋과 애니메이션 명세

## 미술 방향

2D 쿼터뷰, 고대 그리스의 청동·대리석·바다색을 사용한다. 초기 플레이어 64×64 프레임, 일반 적 64×64, 보스 128×128, 바닥 마름모 타일 64×32, 아이콘 64×64를 기준으로 한다. 쿼터뷰에 맞춘 앞/뒤 대각 4방향 스프라이트와 마우스 조준 360도 공격을 분리한다. 이 규격은 원화 제작 전 가독성 테스트로 확정한다. 기존 정사각형 탑다운 바닥 규격은 이 규격으로 대체한다.

## 최소 모션

| 대상 | 상태 | 방향당 프레임 초안 | 판정 관계 |
|---|---|---:|---|
| 플레이어 | idle/run | 4/6 | 이동 상태 반영 |
| 플레이어 | attack/cast | 각 6 | 선딜→발사→후딜에 시각 동기화 |
| 플레이어 | dodge/hit/death | 4/2/6 | 무적 구간 표시/피격/사망 |
| 일반 적 | idle/run/attack/hit/death | 4/6/6/2/6 | 사망 즉시 공격·충돌 중단 |
| 보스 | idle/move/telegraph/attack/hit/death | 별도 정의 | 예고와 실제 범위 일치 |

4방향 전체 제작 시 플레이어 136프레임, 일반 적 한 종 96프레임으로 제작량이 커진다. 첫 전투 프로토타입은 좌우 2방향과 반전, 간단한 무기 회전/반동으로 시작하고, 판정이 안정된 뒤 4방향으로 확장한다. 죽음은 초기 공통 방향을 써도 된다. 무기 외형은 처음에는 교체하지 않고 아이콘과 효과만 교체해 장비별 모션 폭증을 막는다.

## 상태와 타격감

- 플레이어: Idle ↔ Move → Windup → Release → Recovery. Hit는 초기 짧은 시각 반응으로만 처리하며, 경직은 별도 상태효과일 때만 행동을 끊는다. Death는 모든 상태보다 우선한다.
- 적: Spawn → Chase → Telegraph → Attack → Recovery, 또는 Stagger → Chase, 어느 상태든 Death로 전환 가능.
- 공격 타이밍은 게임 로직이 소유한다. 애니메이션 이벤트만으로 피해를 결정하지 않는다.
- 피격 시 0.08초 색상 flash, 작은 넉백, 적중 VFX와 SFX. 강한 타격의 화면 정지/흔들림은 선택 설정으로 제한한다.
- 사망 플래그를 먼저 적용하고 공격 취소, 충돌 제거, 사망 모션, 드롭 1회, 잔상/시체 정리 순서로 처리한다.
- 투사체는 생성 광원/본체/꼬리/적중/소멸 표현을 분리하고 적중 없는 시간 만료도 처리한다.
- 번개 연쇄 선, 파도 흔적, 참격 부채꼴, 보스 장판은 초기 엔진의 선/도형/입자 표현으로 구현한다.

## 제작·조달 순서

1. 개발자 도형 에셋으로 이동·공격·피격·사망을 먼저 확인한다.
2. [Kenney 에셋 목록](https://kenney.nl/assets) 등에서 타일, UI, 임시 효과음을 검토한다. 사용할 개별 팩을 선택한 뒤 라이선스와 출처를 기록한다. 현재 선택/다운로드한 팩은 없다.
3. 플레이어·키클롭스·고유 장비 아이콘은 자체 제작 대상으로 둔다. 이미지 생성은 원화와 아이콘 후보에 활용할 수 있다.
4. 생성 이미지로 연속 스프라이트를 자동 완성한다고 가정하지 않는다. 프레임 간 비율·방향·무기 위치를 수작업 정리하거나 리깅/프레임 편집으로 보완한다.
5. 스프라이트 시트 export → 피벗/프레임 이름 검증 → 엔진 import → 실제 크기에서 애니메이션 검수 순으로 진행한다.

그림 생성과 유료 에셋 구매는 아직 수행하지 않는다. 다음 구현 단계에서 기본 화면을 만든 뒤 필요한 제작 목록을 확정한다.

## 최소 에셋 목록

스토리 연출용 정지 일러스트는 오프닝 3장 + 엔딩 3장, 총 6장을 별도 추가한다. 첫 데모에는 오프닝을 연결하고, 엔딩은 캠페인 완료 테스트 장면에서 먼저 검증한다. 구도와 대사는 [스토리 연출 명세](06-story-sequences.md)를 따른다.

플레이어 1세트, 적 3세트, 보스 1세트, 해안 타일 1세트, 장식 약 10개, 주스킬 VFX 3세트, 공통 피격/사망/회피 효과, 장비 아이콘 12개, 스킬 아이콘 8개, 등급 테두리 6개, UI 패널/버튼, 공격·피격·사망·가차·UI 효과음 약 12개, 전투/거점 음악 각 1개.

파일명은 `actor_action_direction_frame` 규칙을 사용한다. 픽셀 정렬, 동일 캔버스, 발밑 기준 피벗, 투명 배경을 유지한다. 사운드는 동시 재생 수와 음량 제한을 둔다.

모든 외부 에셋은 `game/assets/asset-manifest.csv`에 파일 경로, 저작자, 원본 URL, 라이선스, 수정 내역, 출처 표시 필요 여부를 기록한다. 원본 작업 파일과 실행용 export를 구분한다. 대형 원본은 필요 시 Git LFS를 도입하되 저장소 한도와 팀 도구를 확인한 뒤 결정한다.
