# v0.2.20 — 전투 준비 로딩과 대규모 전투 최적화

- 지형 충돌 데이터를 캐시하고 몬스터의 고정 모델 부품·재질을 공유/병합했습니다. 화면 밖 몬스터의 모델 갱신을 줄이고, 입장 시 반투명 로딩 화면에서 주변 모델 준비 후 전투를 시작합니다.
- 망령과 잿불 사제, 엔드게임 보스 변형 엠푸사를 추가했습니다. 엠푸사는 피할 수 있는 화염 부채와 내려찍기를 사용합니다.
- 가챠 기회는 레벨당 3회에서 시작해 10레벨마다 1회 증가, 최대 12회입니다. 이전 저장의 사용 횟수는 유지하며 증가한 한도만 추가합니다. 레벨 100 최종 보스의 기회 보충도 새 한도를 따릅니다.
- 소환수 기본 체력은 플레이어 체력의 125%, 기본 피해 감소는 25%로 조정했습니다. 생존 보조를 강화하고 적 투사체에도 피해 감소가 적용되도록 수정했습니다. 공격력·방어·이동 유지형 버프를 소환수에 반영합니다. 원소 버프의 기존 적용은 유지됩니다.
- 미니맵은 지형 외곽과 통로를 포함해 중앙에 맞추며 별도 보스방 좌표 표시도 수정했습니다.

검증: 기존 회귀 검사 및 신규 충돌 판정/가챠 저장 이관/소환수/미니맵 검사를 통과했습니다. 같은 측정에서 지형 판정 1만 회 약 441→120ms, 사티로스 렌더링 부품 117→29개. QHD·RTX 5070 Ti·60마리 AI 활성 검사용 전투에서 프레임 시간 중앙값 8.83ms, p95 12.325ms였습니다. 짧은 합성 검사이며 모든 장비·스킬 조합의 장시간 FPS를 보장하지 않습니다.

Windows 실행 검증 대상입니다. macOS/Linux는 패키징 제공이며 해당 OS에서 실행은 검증하지 않았습니다. 기존 저장을 유지합니다.
