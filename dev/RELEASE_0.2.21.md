# v0.2.21 — 공격 이펙트 준비 지연 완화

- 검 궤적의 동일한 셰이더와 메시를 여러 공격이 공유하도록 변경했습니다. 공격마다 새 효과 번호를 사용할 때 같은 렌더링 리소스를 다시 만드는 비용을 줄입니다. 각 효과의 범위와 사라지는 애니메이션은 독립적으로 유지합니다.
- 입장 로딩 중 검 궤적·검기·원소 효과를 실제로 한 번 표시해 첫 공격의 준비 부담을 분산합니다.
- 입력 이벤트를 렌더 프레임 단위로 모으는 설정을 해제했습니다.
- 모델, 그림자, 조명, 해상도는 기존 품질을 유지합니다. macOS의 화질을 자동으로 낮추지 않습니다.

검증: 입력 처리 직후 근접 피해/모션이 설정됨, 셰이더·메시 공유, 개별 효과 애니메이션 독립성, Windows 렌더링 및 로딩 종료 검사 통과. macOS 실기기가 없어 보고된 1~2초 지연의 해결 여부는 미검증입니다. 이 버전으로 맥에서 첫 공격과 반복 공격을 비교해 주세요.

v0.2.20의 전투 최적화·가챠·소환수·미니맵 수정이 포함됩니다. 기존 저장과 화면 설정은 유지합니다.
